# 内部服务-票务服务需求文档 v1.0.0

## 1. 服务概述

票务服务内部接口为HCD系统内部其他服务提供票务相关的功能支持，包括车票信息查询、车票创建、车票状态更新等功能，为订单服务等提供必要的票务数据支持。

## 2. 技术规范

### 2.1 核心技术栈

- **编程语言**: Java 17
- **框架**: Spring Boot 3.2.7
- **微服务**: Spring Cloud 2023.0.0
- **服务治理**: Spring Cloud Alibaba 2023.0.0.0-RC1
- **数据库**: MySQL 8.0.33
- **ORM框架**: MyBatis Plus 3.5.5
- **缓存**: Redis

### 2.2 架构设计

```
ticket-parent/
├── ticket-ao/                # 应用对象（DTO）
├── ticket-api/               # API接口和Feign客户端
├── ticket-biz/               # 业务逻辑实现
├── ticket-bo/                # 业务对象（实体）
├── ticket-constant/          # 常量定义
└── ticket-boot/              # 服务启动模块
```

## 3. 功能需求

### 3.1 车票创建功能

- **功能描述**: 创建车票信息
- **输入参数**: 订单ID、座位预订ID、票价、出发时间、结束时间、乘车人ID、出发站ID、到达站ID等
- **输出结果**: 创建的车票信息
- **业务规则**: 
  - 内部服务调用，通过Feign客户端进行通信
  - 车票创建时必须关联订单
  - 车票创建时必须关联座位预订
  - 车票状态初始化为未使用

### 3.2 根据订单ID查询车票功能

- **功能描述**: 根据订单ID查询关联的车票信息
- **输入参数**: 订单ID
- **输出结果**: 车票信息列表
- **业务规则**: 
  - 内部服务调用，通过Feign客户端进行通信
  - 只能查询订单关联的车票信息

### 3.3 根据订单信息取消车票功能

- **功能描述**: 根据订单信息取消车票
- **输入参数**: 订单ID等
- **输出结果**: 取消结果
- **业务规则**: 
  - 内部服务调用，通过Feign客户端进行通信
  - 取消车票后更新车票状态为已取消
  - 取消车票后释放关联的座位

## 4. API接口

### 4.1 内部服务接口

| 接口路径 | 方法 | 功能描述 | 请求参数 | 响应格式 | 调用方 |
|---------|------|---------|---------|---------|--------|
| /api/v1/internal/ticket/ticket/info | POST | 获取车票信息 | List<Long> ticketIds | Result<List<TicketRES>> | 订单服务 |
| /api/v1/internal/ticket/ticket/create | POST | 创建车票 | TicketDTO | Result<Void> | 订单服务 |
| /api/v1/internal/ticket/ticket/update | PUT | 更新车票信息 | TicketDTO | Result<Void> | 订单服务 |
| /api/v1/internal/ticket/ticket/list | POST | 批量查询车票信息 | List<Long> ticketIds | Result<List<TicketRES>> | 订单服务 |
| /api/v1/internal/ticket/ticket/by-order | GET | 根据订单ID获取车票 | orderId | Result<List<TicketRES>> | 订单服务 |
| /api/v1/internal/ticket/ticket/cancel | POST | 根据订单取消车票 | CancelTicketDTO | Result<Void> | 订单服务 |

## 5. 依赖关系

- **依赖服务**: 列车座位服务、用户服务
- **被依赖服务**: 订单服务

## 6. 数据安全

- 所有接口仅允许内部服务调用
- 使用Feign客户端进行服务间通信
- 接口调用需经过API网关的认证授权
