# 小程序端-用户服务需求文档 v1.0.0

## 1. 服务概述

用户服务是HCD系统的核心服务之一，主要负责管理用户信息、员工信息、乘车人信息以及用户与乘车人之间的关联关系，为小程序端和管理端提供用户相关的功能支持。

## 2. 技术规范

### 2.1 核心技术栈

- **编程语言**: Java 17
- **框架**: Spring Boot 3.2.7
- **微服务**: Spring Cloud 2023.0.0
- **服务治理**: Spring Cloud Alibaba 2023.0.0.0-RC1
- **数据库**: MySQL 8.0.33
- **ORM框架**: MyBatis Plus 3.5.5
- **缓存**: Redis

### 2.2 架构设计

```
user-parent/
├── user-ao/                # 应用对象（DTO）
├── user-api/               # API接口和Feign客户端
├── user-biz/               # 业务逻辑实现
├── user-bo/                # 业务对象（实体）
├── user-constant/          # 常量定义
└── user-boot/              # 服务启动模块
```

### 2.3 数据库设计

所有数据库表必须继承BaseEO类，包含以下5个通用审计字段：
- `id`: 主键ID（Long类型，使用MyBatis Plus的IdType.ASSIGN_ID）
- `createTime`: 创建时间（LocalDateTime类型）
- `updateTime`: 更新时间（LocalDateTime类型）
- `createPerson`: 创建人（String类型）
- `updatePerson`: 更新者（String类型）

## 3. 功能需求

### 3.1 用户微信登录功能

- **功能描述**: 用户通过微信小程序登录系统
- **输入参数**: 微信登录code
- **输出结果**: 登录成功后的用户信息和token
- **业务规则**: 
  - 首次登录自动创建用户
  - 登录成功后生成JWT token
  - token有效期为7天

### 3.2 用户信息更新功能

- **功能描述**: 更新用户基本信息
- **输入参数**: 用户名、头像、邮箱、手机号等
- **输出结果**: 是否更新成功
- **业务规则**: 
  - 只能更新当前登录用户的信息
  - 手机号必须符合格式要求
  - 邮箱必须符合格式要求

### 3.3 乘车人管理功能

- **功能描述**: 管理用户的乘车人信息
- **输入参数**: 乘车人姓名、证件类型、证件号码等
- **输出结果**: 乘车人信息列表
- **业务规则**: 
  - 每个用户最多添加10个乘车人
  - 乘车人信息必须真实有效
  - 证件号码必须符合格式要求

## 4. API接口

### 4.1 小程序端接口

| 接口路径 | 方法 | 功能描述 | 请求参数 | 响应格式 |
|---------|------|---------|---------|---------|

| /api/v1/app/passenger/delete | DELETE | 删除乘车人 | passengerId | Result<Void> |

## 5. 业务流程

### 5.1 用户微信登录流程

1. 小程序端获取微信登录code
2. 调用用户服务的登录接口
3. 用户服务调用微信接口获取openid
4. 根据openid查询用户信息
5. 若用户不存在，自动创建用户
6. 生成JWT token
7. 返回用户信息和token给小程序端

### 5.2 乘车人添加流程

1. 小程序端提交乘车人信息
2. 调用用户服务的添加乘车人接口
3. 用户服务验证乘车人信息
4. 验证通过后，添加乘车人信息到数据库
5. 建立用户与乘车人的关联关系
6. 返回添加结果给小程序端
