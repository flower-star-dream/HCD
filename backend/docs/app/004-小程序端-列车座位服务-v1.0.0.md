# 小程序端-列车座位服务需求文档 v1.0.0

## 1. 服务概述

列车座位服务是HCD系统的核心服务之一，主要负责管理列车、线路、站点、班次和座位预订等核心业务数据，并为小程序端提供必要的支持，如班次查询、余票查询、座位预订等功能。

## 2. 技术规范

### 2.1 核心技术栈

- **编程语言**: Java 17
- **框架**: Spring Boot 3.2.7
- **微服务**: Spring Cloud 2023.0.0
- **服务治理**: Spring Cloud Alibaba 2023.0.0.0-RC1
- **数据库**: MySQL 8.0.33
- **ORM框架**: MyBatis Plus 3.5.5
- **缓存**: Redis

### 2.3 数据库设计

所有数据库表必须继承BaseEO类，包含以下5个通用审计字段：
- `id`: 主键ID（Long类型，使用MyBatis Plus的IdType.ASSIGN_ID）

- `updateTime`: 更新时间（LocalDateTime类型）

## 3. 功能需求

### 3.1 班次查询功能

- **功能描述**: 查询列车班次列表
- **输入参数**: 起点站ID、终点站ID、出发时间等
- **输出结果**: 班次信息列表
- **业务规则**: 
  - 支持按起点站、终点站、出发时间查询班次
  - 支持分页查询
  - 查询结果包含班次的基本信息和余票数量

### 3.2 班次详情查询功能

- **功能描述**: 查询班次详细信息
- **输入参数**: 班次ID
- **输出结果**: 班次详细信息
- **业务规则**: 
  - 班次详情包含列车信息、线路信息、站点信息、出发时间、结束时间、余票数量等

### 3.3 站点查询功能

- **功能描述**: 查询站点列表
- **输入参数**: 站点名（可选）
- **输出结果**: 站点信息列表
- **业务规则**: 
  - 支持按站点名模糊查询
  - 支持分页查询

### 3.4 余票查询功能

- **功能描述**: 查询指定班次的余票数量
- **输入参数**: 班次ID
- **输出结果**: 余票数量

### 3.5 座位预订功能

- **功能描述**: 预订列车座位
- **输入参数**: 班次ID、座位号、预订状态等
- **输出结果**: 座位预订结果
- **业务规则**: 
  - 预订座位前需检查余票数量
  - 预订成功后生成座位预订记录
  - 预订成功后更新余票数量

## 4. API接口

### 4.1 小程序端接口

| 接口路径 | 方法 | 功能描述 | 请求参数 | 响应格式 |

| /api/v1/app/seat/list | GET | 获取座位预订列表 | SeatReservationPageQueryREQ | Result<PageResult<SeatReservationRES>> |

## 5. 业务流程

### 5.1 班次查询流程

1. 小程序端选择起点站、终点站和出发时间
2. 调用列车座位服务的获取班次列表接口
3. 列车座位服务根据查询条件查询班次列表
4. 返回班次列表给小程序端

### 5.2 座位预订流程

1. 小程序端选择班次并提交座位预订请求
2. 调用列车座位服务的预订座位接口
3. 列车座位服务检查余票数量
4. 余票充足时，生成座位预订记录
5. 更新班次表中的余票数量
6. 返回座位预订结果给小程序端
