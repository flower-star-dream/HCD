# 小程序端-票务服务需求文档 v1.0.0

## 1. 服务概述

票务服务是HCD系统的核心服务之一，主要负责管理车票信息，包括车票的创建、查询、更新和删除等功能。票务服务与列车座位服务紧密协作，实现座位预订、余票查询、车票价格计算等核心业务流程。

## 2. 技术规范

### 2.1 核心技术栈

- **编程语言**: Java 17
- **框架**: Spring Boot 3.2.7
- **微服务**: Spring Cloud 2023.0.0
- **服务治理**: Spring Cloud Alibaba 2023.0.0.0-RC1
- **数据库**: MySQL 8.0.33
- **ORM框架**: MyBatis Plus 3.5.5
- **缓存**: Redis

### 2.2 架构设计

```
ticket-parent/
├── ticket-ao/                # 应用对象（DTO）
├── ticket-api/               # API接口和Feign客户端
├── ticket-biz/               # 业务逻辑实现
├── ticket-bo/                # 业务对象（实体）
├── ticket-constant/          # 常量定义
└── ticket-boot/              # 服务启动模块
```

### 2.3 数据库设计

所有数据库表必须继承BaseEO类，包含以下5个通用审计字段：
- `id`: 主键ID（Long类型，使用MyBatis Plus的IdType.ASSIGN_ID）
- `createTime`: 创建时间（LocalDateTime类型）
- `updateTime`: 更新时间（LocalDateTime类型）
- `createPerson`: 创建人（String类型）
- `updatePerson`: 更新者（String类型）

#### 2.3.1 车票表（hcd_ticket）

| 字段名 | 数据类型 | 描述 |
|-------|---------|------|
| id | bigint | 票号（主键，MyBatis Plus自动生成） |

| update_time | datetime | 更新时间（MyBatis Plus自动填充） |
| create_person | varchar(30) | 创建人（MyBatis Plus自动填充） |

## 3. 功能需求

### 3.1 车票查询功能

- **功能描述**: 查询车票信息
- **输入参数**: 车票ID、订单ID、乘车人ID等
- **输出结果**: 车票信息列表
- **业务规则**: 
  - 支持按多种条件查询车票
  - 支持分页查询

### 3.2 车票取消功能

- **功能描述**: 取消车票
- **输入参数**: 车票ID、用户ID等
- **输出结果**: 是否取消成功
- **业务规则**: 
  - 只有未使用的车票可以取消
  - 取消车票后需释放关联的座位

## 4. API接口

### 4.1 小程序端接口

| 接口路径 | 方法 | 功能描述 | 请求参数 | 响应格式 |
|---------|------|---------|---------|---------|
| /api/v1/app/ticket/list | GET | 获取车票列表 | userId | Result<List<TicketRES>> |
| /api/v1/app/ticket/detail | GET | 获取车票详情 | ticketId | Result<TicketRES> |
| /api/v1/app/ticket/cancel | POST | 取消车票 | ticketId, userId | Result<Void> |

## 5. 业务流程

### 5.1 车票取消流程

1. 小程序端发起取消车票请求
2. 调用票务服务的取消车票接口
3. 票务服务验证车票状态是否为可取消
4. 验证通过后，更新车票状态为已取消
5. 票务服务调用列车座位服务的释放座位接口
6. 列车座位服务更新座位状态为可用
7. 返回取消结果给小程序端

## 6. 依赖关系

- **依赖服务**: 列车座位服务、用户服务
- **被依赖服务**: 订单服务
