# 管理端-票务管理服务需求文档 v1.0.0

## 1. 服务概述

票务管理服务是HCD系统管理端的核心服务之一，主要负责管理车票信息，包括车票查询、状态更新、数据导出等功能，为管理员提供完整的票务管理能力。

## 2. 技术规范

### 2.1 核心技术栈

- **编程语言**: Java 17
- **框架**: Spring Boot 3.2.7
- **微服务**: Spring Cloud 2023.0.0
- **服务治理**: Spring Cloud Alibaba 2023.0.0.0-RC1
- **数据库**: MySQL 8.0.33
- **ORM框架**: MyBatis Plus 3.5.5
- **缓存**: Redis

### 2.2 架构设计

```
ticket-parent/
├── ticket-ao/                # 应用对象（DTO）
├── ticket-api/               # API接口和Feign客户端
├── ticket-biz/               # 业务逻辑实现
├── ticket-bo/                # 业务对象（实体）
├── ticket-constant/          # 常量定义
└── ticket-boot/              # 服务启动模块
```

### 2.3 数据库设计

所有数据库表必须继承BaseEO类，包含以下5个通用审计字段：
- `id`: 主键ID（Long类型，使用MyBatis Plus的IdType.ASSIGN_ID）
- `createTime`: 创建时间（LocalDateTime类型）
- `updateTime`: 更新时间（LocalDateTime类型）
- `createPerson`: 创建人（String类型）
- `updatePerson`: 更新者（String类型）

#### 2.3.1 车票表（hcd_ticket）

| 字段名 | 数据类型 | 描述 |
|-------|---------|------|
| id | bigint | 票号（主键，MyBatis Plus自动生成） |
| order_id | bigint | 所属订单号 |
| seat_reservation_id | bigint | 座位预订号 |
| status | int | 票使用状态 |
| money | decimal(10,2) | 票价 |
| start_time | datetime | 出发时间 |
| end_time | datetime | 结束时间 |
| passenger_id | bigint | 乘车人id |
| start_station_id | varchar(50) | 出发站id |
| end_station_id | varchar(50) | 到达站id |
| create_time | datetime | 创建时间（MyBatis Plus自动填充） |
| update_time | datetime | 更新时间（MyBatis Plus自动填充） |
| create_person | varchar(30) | 创建人（MyBatis Plus自动填充） |
| update_person | varchar(30) | 更新者（MyBatis Plus自动填充） |

## 3. 功能需求

### 3.1 车票列表查询功能

- **功能描述**: 查询车票信息列表
- **输入参数**: 票号、订单ID、乘车人ID、状态、出发时间范围等
- **输出结果**: 车票信息列表
- **业务规则**: 
  - 支持按多种条件查询车票
  - 支持分页查询
  - 只有管理员可以查询车票列表

### 3.2 车票状态更新功能

- **功能描述**: 更新车票使用状态
- **输入参数**: 车票ID、状态（未使用/已使用/已取消）
- **输出结果**: 是否更新成功
- **业务规则**: 
  - 只有管理员可以更新车票状态
  - 车票状态只能按规定的流程更新
  - 已使用的车票不能再更新状态

### 3.3 车票详情查询功能

- **功能描述**: 查询车票详细信息
- **输入参数**: 车票ID
- **输出结果**: 车票详细信息
- **业务规则**: 
  - 只有管理员可以查询车票详情



## 4. API接口

### 4.1 管理端接口

| 接口路径 | 方法 | 功能描述 | 请求参数 | 响应格式 |
|---------|------|---------|---------|---------|
| /api/v1/mgmt/ticket/list | GET | 获取车票列表 | TicketPageQueryREQ | Result<PageResult<TicketRES>> |
| /api/v1/mgmt/ticket/detail | GET | 获取车票详情 | ticketId | Result<TicketRES> |
| /api/v1/mgmt/ticket/status | PUT | 更新车票状态 | TicketStatusChangeREQ | Result<Void> |

## 5. 业务流程

### 5.1 车票列表查询流程

1. 管理端发起车票列表查询请求
2. 调用票务服务的获取车票列表接口
3. 票务服务验证管理员权限
4. 验证通过后，根据查询条件查询车票列表
5. 返回车票列表给管理端

### 5.2 车票状态更新流程

1. 管理端发起车票状态更新请求
2. 调用票务服务的更新车票状态接口
3. 票务服务验证管理员权限
4. 验证通过后，更新车票状态
5. 返回更新结果给管理端



## 6. 依赖关系

- **依赖服务**: 列车座位服务、订单服务
- **被依赖服务**: 无

- 敏感数据传输采用HTTPS
