# 管理端-用户管理服务需求文档 v1.0.0

## 1. 服务概述

管理端用户管理服务是HCD系统管理端的核心服务之一，主要负责管理系统用户和员工信息，包括用户查询、用户状态管理、员工管理等功能，为管理员提供完整的用户和员工管理能力。

## 2. 技术规范

### 2.1 核心技术栈

- **编程语言**: Java 17
- **框架**: Spring Boot 3.2.7
- **微服务**: Spring Cloud 2023.0.0
- **服务治理**: Spring Cloud Alibaba 2023.0.0.0-RC1
- **数据库**: MySQL 8.0.33
- **ORM框架**: MyBatis Plus 3.5.5
- **缓存**: Redis

### 2.2 架构设计

```
user-parent/
├── user-ao/                # 应用对象（DTO）
├── user-api/               # API接口和Feign客户端
├── user-biz/               # 业务逻辑实现
├── user-bo/                # 业务对象（实体）
├── user-constant/          # 常量定义
└── user-boot/              # 服务启动模块
```

### 2.3 数据库设计

所有数据库表必须继承BaseEO类，包含以下5个通用审计字段：
- `id`: 主键ID（Long类型，使用MyBatis Plus的IdType.ASSIGN_ID）
- `createTime`: 创建时间（LocalDateTime类型）
- `updateTime`: 更新时间（LocalDateTime类型）
- `createPerson`: 创建人（String类型）
- `updatePerson`: 更新者（String类型）

## 3. 功能需求

### 3.1 用户管理功能

#### 3.1.1 用户列表查询功能

- **功能描述**: 查询系统用户列表
- **输入参数**: 用户名、手机号、状态、分页参数等
- **输出结果**: 用户信息列表
- **业务规则**: 
  - 支持按多种条件查询用户
  - 支持分页查询
  - 只有管理员可以查询用户列表

#### 3.1.2 用户状态更新功能

- **功能描述**: 更新用户状态
- **输入参数**: 用户ID、状态（启用/禁用）
- **输出结果**: 是否更新成功
- **业务规则**: 
  - 只有管理员可以更新用户状态
  - 状态只能是启用或禁用
  - 禁用用户后，用户无法登录系统

#### 3.1.3 用户详情查询功能

- **功能描述**: 查询用户详细信息
- **输入参数**: 用户ID
- **输出结果**: 用户详细信息
- **业务规则**: 
  - 只有管理员可以查询用户详情

### 3.2 员工管理功能

#### 3.2.1 员工列表查询功能

- **功能描述**: 查询系统员工列表
- **输入参数**: 员工姓名、手机号、权限等级、状态、分页参数等
- **输出结果**: 员工信息列表
- **业务规则**: 
  - 支持按多种条件查询员工
  - 支持分页查询
  - 只有管理员可以查询员工列表

#### 3.2.2 员工添加功能

- **功能描述**: 添加系统员工
- **输入参数**: 员工姓名、手机号、权限等级、所属站点等
- **输出结果**: 是否添加成功
- **业务规则**: 
  - 只有管理员可以添加员工
  - 员工初始密码为123456
  - 员工权限等级分为普通员工和管理员

#### 3.2.3 员工信息更新功能

- **功能描述**: 更新员工信息
- **输入参数**: 员工ID、员工姓名、手机号、权限等级、所属站点等
- **输出结果**: 是否更新成功
- **业务规则**: 
  - 只有管理员可以更新员工信息
  - 普通员工不能修改自己的权限等级

#### 3.2.4 员工状态更新功能

- **功能描述**: 更新员工状态
- **输入参数**: 员工ID、状态（启用/禁用）
- **输出结果**: 是否更新成功
- **业务规则**: 
  - 只有管理员可以更新员工状态
  - 状态只能是启用或禁用
  - 禁用员工后，员工无法登录系统

#### 3.2.5 员工删除功能

- **功能描述**: 删除系统员工
- **输入参数**: 员工ID
- **输出结果**: 是否删除成功
- **业务规则**: 
  - 只有管理员可以删除员工
  - 不能删除当前登录的管理员

## 4. API接口

### 4.1 管理端接口

| 接口路径 | 方法 | 功能描述 | 请求参数 | 响应格式 |
|---------|------|---------|---------|---------|
| /api/v1/mgmt/user/list | GET | 获取用户列表 | UserPageQueryREQ | Result<PageResult<UserEO>> |
| /api/v1/mgmt/user/detail | GET | 获取用户详情 | userId | Result<UserEO> |
| /api/v1/mgmt/user/status | PUT | 更新用户状态 | status, userId | Result<Void> |
| /api/v1/mgmt/employee/list | GET | 获取员工列表 | EmployeePageQueryREQ | Result<PageResult<EmployeeEO>> |
| /api/v1/mgmt/employee/add | POST | 添加员工 | EmployeeREQ | Result<Void> |
| /api/v1/mgmt/employee/update | PUT | 更新员工信息 | EmployeeREQ | Result<Void> |
| /api/v1/mgmt/employee/delete | DELETE | 删除员工 | employeeId | Result<Void> |
| /api/v1/mgmt/employee/status | PUT | 更新员工状态 | status, employeeId | Result<Void> |

## 5. 业务流程

### 5.1 用户列表查询流程

1. 管理端发起用户列表查询请求
2. 调用用户服务的获取用户列表接口
3. 用户服务验证管理员权限
4. 验证通过后，根据查询条件查询用户列表
5. 返回用户列表给管理端

### 5.2 员工添加流程

1. 管理端发起添加员工请求
2. 调用用户服务的添加员工接口
3. 用户服务验证管理员权限
4. 验证通过后，添加员工信息到数据库
5. 返回添加结果给管理端

### 5.3 员工状态更新流程

1. 管理端发起员工状态更新请求
2. 调用用户服务的更新员工状态接口
3. 用户服务验证管理员权限
4. 验证通过后，更新员工状态
5. 返回更新结果给管理端

## 7. 数据安全

- 所有接口调用需经过认证授权
- 只有管理员可以访问管理端接口
- 敏感数据传输采用HTTPS
- 接口调用频率限制
- 员工密码采用加密存储
