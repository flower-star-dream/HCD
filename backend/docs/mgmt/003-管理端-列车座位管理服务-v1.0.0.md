# 管理端-列车座位管理服务需求文档 v1.0.0

## 1. 服务概述

列车座位管理服务是HCD系统管理端的核心服务之一，主要负责管理列车、线路、站点、班次和座位预订等核心业务数据，为管理员提供完整的列车座位管理能力。

## 2. 技术规范

### 2.1 核心技术栈

- **编程语言**: Java 17
- **框架**: Spring Boot 3.2.7
- **微服务**: Spring Cloud 2023.0.0
- **服务治理**: Spring Cloud Alibaba 2023.0.0.0-RC1
- **数据库**: MySQL 8.0.33
- **ORM框架**: MyBatis Plus 3.5.5
- **缓存**: Redis

### 2.2 架构设计

```
trainSeat-parent/
├── trainSeat-ao/                # 应用对象（DTO）
├── trainSeat-api/               # API接口和Feign客户端
├── trainSeat-biz/               # 业务逻辑实现
├── trainSeat-bo/                # 业务对象（实体）
├── trainSeat-constant/          # 常量定义
└── trainSeat-boot/              # 服务启动模块
```

### 2.3 数据库设计

所有数据库表必须继承BaseEO类，包含以下5个通用审计字段：
- `id`: 主键ID（Long类型，使用MyBatis Plus的IdType.ASSIGN_ID）
- `createTime`: 创建时间（LocalDateTime类型）
- `updateTime`: 更新时间（LocalDateTime类型）
- `createPerson`: 创建人（String类型）
- `updatePerson`: 更新者（String类型）

## 3. 功能需求

### 3.1 列车管理功能

- **功能描述**: 管理列车信息
- **输入参数**: 列车名、列车型号、座位数、服务年数等
- **输出结果**: 列车信息列表
- **业务规则**: 
  - 支持添加、查询、更新、删除列车信息
  - 只有管理员可以管理列车信息

### 3.2 线路管理功能

- **功能描述**: 管理线路信息
- **输入参数**: 线路名、起点站ID、终点站ID、站点数等
- **输出结果**: 线路信息列表
- **业务规则**: 
  - 支持添加、查询、更新、删除线路信息
  - 只有管理员可以管理线路信息

### 3.3 站点管理功能

- **功能描述**: 管理站点信息
- **输入参数**: 站点名、地址等
- **输出结果**: 站点信息列表
- **业务规则**: 
  - 支持添加、查询、更新、删除站点信息
  - 只有管理员可以管理站点信息

### 3.4 班次管理功能

- **功能描述**: 管理班次信息
- **输入参数**: 列车ID、线路ID、列车长、出发时间、结束时间等
- **输出结果**: 班次信息列表
- **业务规则**: 
  - 支持添加、查询、更新、删除班次信息
  - 只有管理员可以管理班次信息
  - 班次创建后，自动计算余票数量

### 3.5 座位预订管理功能

- **功能描述**: 管理座位预订信息
- **输入参数**: 班次ID、座位号、预订状态等
- **输出结果**: 座位预订信息列表
- **业务规则**: 
  - 支持查询、更新座位预订信息
  - 只有管理员可以管理座位预订信息

## 5. 业务流程

### 5.1 列车添加流程

1. 管理端发起添加列车请求
2. 调用列车座位服务的添加列车接口
3. 列车座位服务验证管理员权限
4. 验证通过后，添加列车信息到数据库
5. 返回添加结果给管理端

### 5.2 线路添加流程

1. 管理端发起添加线路请求
2. 调用列车座位服务的添加线路接口
3. 列车座位服务验证管理员权限
4. 验证通过后，添加线路信息到数据库
5. 返回添加结果给管理端

### 5.3 站点添加流程

1. 管理端发起添加站点请求
2. 调用列车座位服务的添加站点接口
3. 列车座位服务验证管理员权限
4. 验证通过后，添加站点信息到数据库
5. 返回添加结果给管理端

### 5.4 班次添加流程

1. 管理端发起添加班次请求
2. 调用列车座位服务的添加班次接口
3. 列车座位服务验证管理员权限
4. 验证通过后，添加班次信息到数据库
5. 根据列车座位数计算初始余票数量
6. 返回添加结果给管理端
