# HCD项目前端需求文档（后管端）v1.0.0

## 1. 项目概述

### 1.1 项目背景
HCD项目全称：火车订票系统，是一个面向铁路客运的综合性在线订票平台。后台管理系统为运营人员提供用户管理、订单处理、运力调度、数据分析等核心业务功能。

### 1.2 项目目标
构建一个功能完善、操作便捷、安全可靠的后台管理系统，实现火车订票业务的全面数字化管理，提升运营效率，优化用户体验。

### 1.3 目标用户
- **超级管理员**：系统最高权限，可管理所有功能模块
- **管理员**：具备大部分管理权限，可管理普通成员
- **运营成员**：基础操作权限，负责日常业务处理

## 2. 功能需求

### 2.1 登录认证模块

#### 2.1.1 功能描述
提供安全可靠的员工登录认证机制，确保系统访问的安全性。

#### 2.1.2 功能需求
- **多方式登录**：支持员工账号和手机号两种登录方式
- **输入验证**：
  - 密码长度：6-20位字符
  - 手机号格式：中国大陆手机号格式验证（1开头，11位数字）
- **安全机制**：
  - JWT Token认证
  - 登录状态持久化存储
  - 自动登录保持（7天有效期）
- **错误处理**：
  - 用户名/手机号不存在提示
  - 密码错误提示
  - 账户禁用提示

#### 2.1.3 页面元素
- 登录表单（用户名/手机号输入框、密码输入框）
- 登录按钮
- 记住密码选项
- 系统Logo和标题

### 2.2 员工管理模块

#### 2.2.1 功能描述
实现员工账号的创建、编辑、权限分配和状态管理，构建完善的权限管理体系。

#### 2.2.2 功能需求
- **员工列表展示**：
  - 员工编号、姓名、用户名、手机号、邮箱、权限级别、状态、创建时间
  - 分页展示（每页10/20/50条可选）
- **搜索筛选**：
  - 按姓名/用户名/手机号搜索
  - 按状态筛选（启用/禁用）
  - 按权限级别筛选
- **员工操作**：
  - 新增员工（填写基本信息，设置初始密码）
  - 编辑员工信息（除用户名外其他信息可修改）
  - 删除员工（支持批量删除）
  - 状态切换（启用/禁用）
  - 重置密码
- **权限管理**：
  - 权限级别设置（超级管理员/管理员/成员）
  - 权限继承规则（管理员只能管理成员）
  - 权限变更日志记录

#### 2.2.3 权限控制规则
- 超级管理员：可管理所有员工
- 管理员：只可管理成员级别的员工
- 成员：无员工管理权限

### 2.3 用户管理模块

#### 2.3.1 功能描述
管理平台注册用户，提供用户信息查看、状态管理等基本操作功能。

#### 2.3.2 功能需求
- **用户列表展示**：
  - 用户编号、用户名、手机号、邮箱、关联乘客、状态、注册时间
  - 用户状态统计（正常/冻结数量）
- **搜索筛选**：
  - 按用户名/手机号搜索
  - 按状态筛选（正常/冻结）
  - 按注册时间范围筛选
- **用户操作**：
  - 查看用户详情（基本信息、订单记录、乘客信息）
  - 状态管理（正常/冻结切换）
  - 批量操作支持

#### 2.3.3 用户状态定义
- **正常（1）**：用户可正常登录和使用系统
- **冻结（0）**：用户被限制登录和下单

### 2.4 订单管理模块

#### 2.4.1 功能描述
提供订单的全生命周期管理，包括订单查询、状态跟踪、详情查看和取消操作。

#### 2.4.2 功能需求
- **订单列表展示**：
  - 订单编号、用户、车次、出发站、到达站、出发时间、订单状态、订单金额、创建时间
  - 订单状态统计（待支付/已支付/已出票/已完成/已取消/已退款）
- **订单状态管理**：
  - 状态标签页切换查看
  - 状态颜色标识（不同状态不同颜色）
  - 状态变更时间记录
- **订单操作**：
  - 查看订单详情（车票信息、乘客信息、支付信息）
  - 取消订单（待支付状态下可操作）
  - 订单备注添加
- **搜索筛选**：
  - 按订单号/用户名/手机号搜索
  - 按车次搜索
  - 按日期范围筛选
  - 按状态筛选

#### 2.4.3 订单状态流转
```
创建订单 → 待支付 → 已支付 → 已出票 → 已完成
     ↓         ↓        ↓        ↓
   已取消     已退款   已退款   已退款
```

### 2.5 运力中心模块

#### 2.5.1 列车管理
- **功能需求**：
  - 列车车次信息管理（车次号、列车类型、座位配置）
  - 列车状态管理（运行/停运）
  - 列车基本信息维护

#### 2.5.2 班次管理
- **功能需求**：
  - 班次排班计划制定
  - 班次状态跟踪
  - 班次信息编辑

#### 2.5.3 座位预订管理
- **功能需求**：
  - 座位分配查看
  - 座位预订统计
  - 座位状态管理

#### 2.5.4 线路管理
- **功能需求**：
  - 线路规划管理
  - 线路站点配置
  - 线路状态维护

#### 2.5.5 站点管理
- **功能需求**：
  - 车站基础信息管理
  - 站点状态管理
  - 站点间关联配置

### 2.6 系统管理模块

#### 2.6.1 操作日志
- **功能需求**：
  - 用户操作记录跟踪
  - 操作类型分类
  - 操作时间、操作人员记录
  - 异常操作预警

#### 2.6.2 系统配置
- **功能需求**：
  - 系统参数配置
  - 业务规则设置
  - 通知模板管理

## 3. 非功能性需求

### 3.1 性能需求
- **响应时间**：
  - 页面加载时间 ≤ 3秒
  - 数据查询响应时间 ≤ 2秒
  - 表单提交响应时间 ≤ 3秒
- **并发能力**：
  - 支持100个并发用户同时在线
  - 高峰期响应时间不超过5秒
- **数据处理能力**：
  - 支持10万条数据快速检索
  - 批量操作支持1000条数据同时处理

### 3.2 可靠性需求
- **系统可用性**：99.9%的年可用性
- **数据备份**：每日自动数据备份
- **故障恢复**：系统故障30分钟内恢复
- **数据一致性**：保证数据操作的原子性和一致性

### 3.3 安全性需求
- **身份认证**：JWT Token认证机制
- **权限控制**：基于角色的访问控制（RBAC）
- **数据加密**：敏感数据传输加密
- **操作审计**：完整的操作日志记录
- **防攻击能力**：SQL注入、XSS攻击防护

### 3.4 易用性需求
- **用户界面**：简洁直观，符合操作习惯
- **操作反馈**：及时的操作结果反馈
- **错误提示**：友好的错误信息提示
- **帮助文档**：在线帮助和操作指南

### 3.5 兼容性需求
- **浏览器支持**：Chrome、Firefox、Safari、Edge最新版本
- **分辨率适配**：支持1366×768及以上分辨率
- **移动适配**：支持平板设备访问

## 4. 数据需求

### 4.1 数据精度
- **金额数据**：精确到分（0.01元）
- **时间数据**：精确到秒
- **坐标数据**：精确到小数点后6位

### 4.2 数据完整性
- **必填字段验证**：关键信息必须填写
- **数据格式验证**：符合业务规则要求
- **数据关联性**：保持数据间的逻辑一致性

### 4.3 数据存储
- **数据保留期**：业务数据保留3年
- **日志数据**：操作日志保留1年
- **备份策略**：每日全量备份，每小时增量备份

## 5. 接口需求

### 5.1 接口规范
- **协议标准**：RESTful API设计规范
- **数据格式**：JSON数据交换格式
- **编码标准**：UTF-8编码
- **版本控制**：API版本号管理

### 5.2 接口性能
- **响应格式**：统一响应格式
- **错误处理**：标准化错误码和错误信息
- **分页处理**：统一分页参数和返回格式

## 6. 部署需求

### 6.1 运行环境
- **Web服务器**：Nginx 1.20+
- **浏览器支持**：现代浏览器（ES6+支持）
- **网络环境**：支持HTTPS协议

### 6.2 部署要求
- **容器化部署**：支持Docker容器部署
- **负载均衡**：支持多实例部署
- **静态资源**：CDN加速支持

## 7. 维护需求

### 7.1 监控需求
- **性能监控**：页面加载时间、接口响应时间
- **错误监控**：JavaScript错误、接口异常
- **用户行为**：用户操作路径、功能使用频率

### 7.2 日志需求
- **操作日志**：用户操作记录
- **系统日志**：系统运行状态
- **错误日志**：异常情况记录

### 7.3 更新维护
- **热更新支持**：支持无停机更新
- **版本回滚**：支持版本快速回滚
- **配置管理**：支持运行时配置调整

## 8. 附录

### 8.1 术语定义
- **JWT**：JSON Web Token，一种开放标准（RFC 7519）
- **RBAC**：基于角色的访问控制（Role-Based Access Control）
- **RESTful**：一种软件架构风格，用于设计网络应用程序
- **CDN**：内容分发网络（Content Delivery Network）
